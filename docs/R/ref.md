# All Functions
functions in  CGDRO R package, including `cgdro_()`, `predict_cgdro_()`, `infer_cgdro_()`, and `summary_cgdro_()`.


| Function | Description |
|-----------|--------------|
| [`cgdro_()`](ref/cgdro.ipynb) | Fit Conditional Group DRO model in the target domain. |
| [`infer_cgdro_()`](ref/infer.ipynb) | Construct confidence intervals and perform statistical inference for fitted CGDRO models. |
| [`predict_cgdro_()`](ref/predict.ipynb) | Generate predictions from fitted CGDRO models on the target domain. |
| [`summary_cgdro_()`](ref/summary.ipynb) | Summarize the training and inference results, including group weights, coefficient estimators and confidence intervals. |
