# All Modules
Modules in CGDRO Python package, including `Regression.linear.ld`, `Regression.linear.hd`, `Regression.ml`, and `Classification`.

| [`Regression.ml`](ref/reg_ml.ipynb) | Fit CGDRO in machine learning prediction model. |
| [`Classification`](ref/cls.ipynb) | Fit CGDRO in classification model. |
